# Avengers: Doomsday Countdown ⚡

A dramatic countdown timer tracking the days, hours, minutes, and seconds until the release of Avengers: Doomsday on December 18, 2026.

## What is Avengers: Doomsday Countdown?

Avengers: Doomsday Countdown is a themed countdown timer that displays the time remaining until the anticipated Marvel film release. It features:

- Months, days, hours, minutes, seconds countdown
- Cyberpunk-inspired design with glowing green accents
- Live status indicator with pulsing animation
- Dramatic "System Alert" styling fitting the film's theme

## Key Features

- **Months, Days, Hours, Minutes, Seconds:** Full breakdown of remaining time
- **Auto-Updating:** Updates every second in real-time
- **Themed Design:** Dark background with neon green accents
- **Status Indicator:** Pulsing "System Alert" with live status
- **Responsive:** Works on desktop, tablet, and mobile
- **Glowing Effects:** Subtle glow animations on numbers
- **Glassmorphism:** Frosted glass effect on the clock container

## How to Use

1. Open the page in your browser
2. View the countdown showing time until December 18, 2026
3. Watch it tick down in real-time

### Target Date

**December 18, 2026** — Avengers: Doomsday release date

## Technology Stack

- **HTML5:** Structure
- **CSS3:** Themed styling with animations and glassmorphism
- **Vanilla JavaScript:** Countdown logic with setInterval
